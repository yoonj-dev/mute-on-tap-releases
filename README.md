## ✨ What is Mute On Tap?
Mute On Tap is a lightweight utility that automatically silences your Windows audio whenever you connect specific devices. No more accidental "loud audio" moments!

- **Smart Detection**: Knows when headphones or speakers are connected.
- **Auto-Mute**: Instantly applies silence based on your rules.
- **Tray Mode**: Runs quietly in the background.
- **Customizable**: Set rules for specific hardware IDs.

## 🛠️ Installation & Setup
1. **Download** the latest `.zip` from the [Releases](https://github.com/yoonj-dev/mute-on-tap-releases/releases) page.
2. **Extract** the folder to a location of your choice.
3. **Run** `mute_on_tap.exe`.
4. **Choose** which device types to auto-mute.
5. **Save** and enjoy the silence!
